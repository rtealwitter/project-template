# Start here

1. Fork this repository and keep your fork public. Rename it if you want a project-specific name.
2. Clone it or open it in a coding agent.
3. Keep `README.md` at the top level of the repository. Use it to answer all four assignment prompts: problem statement, dataset, algorithms, and results and visuals. Its headings are suggestions; organize the report around what you want to explain.
4. Replace `src/analysis.py` with code that creates your results and figures. Document the data and dependencies so someone else can run it.
5. Keep a short account of important AI instructions, checks, and decisions in `AI_USAGE.md`, or state that you did not use AI.
6. Open the **Actions** tab on GitHub and enable workflows if GitHub asks. Push your changes and read the result of **Check project requirements**.
7. Put your public repository URL in `REPOSITORY_URL.txt`.
8. Push your completed work to GitHub. On the final-project Programming Assignment in Gradescope, choose the GitHub submission option and select your repository and branch. Submit the code, figures, and `README.md` together this way; a separate README upload is not required.
9. Read the automated results and fix missing files or unfinished prompts. If you make changes, push them and resubmit on Gradescope.

The checker looks for files, figures, a reproduction command, and unfinished template prompts.
It does not require particular report headings or a result that beats the baseline.
The instructor manually grades the README answers and analysis for the question, methods, comparisons, figures, and explanation.
