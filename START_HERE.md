# Start here

1. Fork this repository and keep your fork public.
2. Rename the fork if you want a project-specific name.
3. Clone it or open it in a coding agent.
4. Replace the bracketed text in `README.md` as your analysis develops.
5. Replace `src/analysis.py` with code that creates every result and figure.
6. Open the **Actions** tab on GitHub and enable workflows if GitHub asks. Push often and read the result of the **Check project requirements** action.
7. Leave `project-stage.txt` as `proposal2` for Proposal 2. Change it to `final` before the final submission.

The checker reports objective omissions. A green check does not mean that the question, analysis, or explanation is good. Use the assignment rubric for those decisions.
