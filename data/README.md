# Data

Do not commit private data, credentials, or a large dataset to Git.

Document:

- the source URL and, when available, the creator and license;
- the exact file or version used and the date you accessed it;
- the unit of observation and important fields;
- the commands or manual steps needed to download or construct it;
- where the reproduction script expects the files; and
- any privacy, missingness, measurement, or sampling concern.

If the data is small, public, and licensed for redistribution, you may commit it here. Otherwise, keep only this file and let `run.py` download or construct the data when possible.
